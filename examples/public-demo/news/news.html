New: Test transaction data

Transaction dataThe wallet accepts transaction_data of any type in presentation requests (OpenID4VP 1.0). It shows each transaction in the consent dialog and signs its hash into the Key Binding JWT.
EUDI TS12 typesThe wallet checks the payloads of the four TS12 SCA types: payment, login, account access and e-mandate. The consent dialog sums each one up, such as "Pay €12.50 to Demo Shop".
Demo payment accountGet it from the demo issuer. On the demo verifier, choose Demo payment account to confirm a payment with it.
Transaction templatesBuild entries under Templates > Transaction templates. Every request on the demo verifier can add transaction data from a template or as JSON.

Details are in the transaction data documentation. Please report problems on GitHub.

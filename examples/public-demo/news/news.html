New: Test the Digital Credentials API

Browser extensionThe eudi-dev extension answers navigator.credentials.get() with this wallet. You approve the presentation in a wallet window, without a phone.
Any verifierThe extension works with every verifier page that uses the standard API. Your own page needs no change.
Demo verifierChoose Digital Credentials API under Delivery. Requests can be signed, unsigned or multisigned.
Your walletThe extension uses eudi-test.dev by default. Set a local wallet or your own server in its popup.

Install from the Chrome Web Store

For other ways to install it, open How to use and choose Browser extension. Details are in the extension documentation. Please report problems on GitHub.

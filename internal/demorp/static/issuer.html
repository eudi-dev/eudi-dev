EUDI Test Demo Issuer

A minimal OpenID4VCI issuer for demo purposes

This issuer hands out a signed Demo Event Ticket (SD-JWT VC) over OpenID4VCI, and any credential template this wallet knows. Create an offer and open it in the wallet on this host, or copy the offer URI into any wallet that can reach this server.

The demo ticket, or a credential issued from one of this wallet's templates (the built-in EUDI and German PID among them), signed under the trust profile its type belongs to.

Grant

The offer carries the code, so the wallet redeems it without any sign-in.

Authorization

You sign in here (alice / alice) while the wallet redeems the offer.

Status list

The ticket carries no status reference, so nothing can revoke it.

Issuance

The credential is issued at once.

Copies

The wallet receives a single credential.

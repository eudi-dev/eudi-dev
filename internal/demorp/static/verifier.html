EUDI Test Demo Verifier

A minimal OpenID4VP verifier for demo purposes

This verifier asks for a presentation over OpenID4VP, following HAIP 1.0: a signed request object behind request_uri, an x509_hash client id, dcql_query and direct_post.jwt with an encrypted response. It then checks the response: issuer signature, revocation, key binding, sd_hash, nonce and audience.

Ticket

Build a DCQL query by hand. Each path selects a claim. A path onto an array of selectively disclosable elements (such as nationalities) discloses an empty array, so end it with [*] for all elements or [n] for one. Nest with dots (address.locality).

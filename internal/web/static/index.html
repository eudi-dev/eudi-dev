Get the CLI

The eudi CLI from eudi-dev decodes, issues and presents credentials. It also runs a local wallet and proxies wallet traffic.

Homebrew
brew install eudi-dev/tap/eudi-dev
Go
go install github.com/eudi-dev/eudi-dev/v3@latest
Docker
docker pull ghcr.io/eudi-dev/eudi-dev

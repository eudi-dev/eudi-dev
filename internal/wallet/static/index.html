How to use this wallet

Test issuance with OpenID4VCI and presentations with OpenID4VP. This wallet supports SD-JWT VC, mdoc, holder binding, status lists and trust lists.

Deliver a credential offer (OpenID4VCI)
/credential-offer?credential_offer_uri=…
Send an authorization request (OpenID4VP)
/authorize?client_id=…&request_uri=…
Trust list (verifiers trusting this wallet's credentials)
/api/trustlist

To open a custom-scheme link in a browser, replace everything before the ? with the matching endpoint URL. Keep the query parameters.

Custom-scheme links via CLI (any platform)
eudi wallet accept 'openid4vp://authorize?client_id=…'
System URL handler (macOS)
eudi wallet register

On macOS, wallet register makes openid4vp://, eudi-openid4vp://, haip-vp://, openid-credential-offer://, haip-vci:// and eu-eaa-offer:// links open in this wallet. See the wallet documentation for all endpoints.

Get the CLI

The eudi CLI from eudi-dev runs this wallet locally. It also decodes, issues and presents credentials, and proxies wallet traffic.

Homebrew
brew install eudi-dev/tap/eudi-dev
Go
go install github.com/eudi-dev/eudi-dev/v2@latest
Docker
docker pull ghcr.io/eudi-dev/eudi-dev
